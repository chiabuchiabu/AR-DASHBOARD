# AR-DASHBOARD

一個簡單的財務分析儀表板，允許使用者上傳 CSV 檔案，
將資料存入資料庫，並將關鍵會計指標轉換為視覺化圖表。

此專案展示如何使用 Python 與 Web 技術，
將傳統的會計資料轉換為互動式的分析工具。

---

## 專案概述

本專案提供一個輕量級的會計資料分析工具。

使用者可以上傳包含財務資料的 CSV 檔案，
系統會自動處理資料、存入資料庫，
並產生視覺化儀表板，幫助分析財務狀況。

資料處理流程：

CSV 上傳  
↓  
資料處理  
↓  
資料庫儲存  
↓  
資料視覺化

## 功能特色

- 上傳 CSV 會計資料
- 自動將資料存入資料庫
- 產生財務分析圖表
- 應收帳款分析
